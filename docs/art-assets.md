# Character artwork — Turnforge v0.2

Asset: [assets/characters.png](../assets/characters.png).

Created with the built-in **imagegen** tool on 30 October 2026, using transparent-background generation. No CLI/API fallback or externally downloaded character pack was used. The original generated PNG is retained unchanged in the project. It contains three equal-width cells: hero, goblin, bandit. Runtime alpha bounds select each figure without modifying the original bitmap.

The game applies horizontal facing, idle bob, movement along the valid BFS route, attack lunge/slash, hit tint, floating damage, and death fade in code. These are lightweight transforms/effects applied to single-pose illustrations, not hand-drawn frame-by-frame walk cycles or four-direction sprite sheets. No 3D models are used.

Put exactly ONE separate full-body character centered in each cell, equal scale, with equal clear transparent margins; no drawn separators, labels, text, UI, terrain, ground plane, floor shadow, checkerboard, decorative background or extra props. Every character must fit entirely inside its own third, including weapons. Keep the top 12% and bottom 12% transparent; characters approximately 65% of canvas height. Left cell: friendly human adventurer, dark short hair, teal-green cloak/scarf, brown boots, simple leather armor, visible steel sword held at side and small round shield. Middle cell: squat goblin raider, olive skin, pointed ears, burnt orange scarf and leather vest, small axe. Right cell: stocky masked enemy bandit, rust-red hood, dark leather armor, short iron club. All three standing in a readable relaxed combat-ready pose, feet visible, front-facing slightly top-down three-quarter view suitable for a top-down square-grid game. Style: crisp polished hand-painted/pixel-inspired 2D fantasy RPG sprites, chibi big head small body, bold dark outlines, clean silhouettes, restrained texture and chunky shading; readable when rendered around 50 pixels tall. Orthographic 2D artwork, no 3D renders, no isometric floor. All have consistent light from upper left and matching outlines. Exactly three characters total. Genuine alpha transparency around and between the three figures. Preserve generous space between figures to allow each equal-width cell to be sampled separately by game code.
